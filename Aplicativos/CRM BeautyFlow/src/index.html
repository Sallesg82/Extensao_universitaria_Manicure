Integração com n8n (Webhooks de Escuta & Envio)
Receba mensagens de clientes no seu fluxo do n8n e envie mensagens pelo n8n via WhatsApp
n8n Workflow Hub
Credenciais para Conectar no n8n (Nó WAHA Account) Pronto para Usar
Preencha estes dados na janela "WAHA account (WAHA API)" do seu n8n para autenticar o nó do WhatsApp.
Para n8n no Docker
Ou http://waha:3000 na rede Docker. Se fora do Docker: http://localhost:3000.
Chave de Autenticação
Cole exatamente no campo API Key do n8n.
Sessão Ativa
Preencha no campo Session dentro do nó de envio de mensagem.
Configuração
Mantenha a opção All no dropdown do n8n.
Passo a passo no n8n: Na janela WAHA account, preencha o Host URL e a API Key e clique em Save. No seu nó de mensagem (ex: Send a text message), selecione essa conta e preencha a Session como beautyflow.
ESCUTA DE MENSAGENS WhatsApp → n8n
Receber Mensagens no n8n (Webhook)
Configure a URL do nó Webhook do seu workflow n8n. Toda mensagem recebida de clientes no WhatsApp será encaminhada instantaneamente ao n8n.
💡 No n8n local, URLs com localhost são roteadas automaticamente para alcançar o host Docker (172.23.0.1).
Como configurar o nó Webhook no n8n & Exemplo JSON
Passo a passo no n8n:
1. No seu n8n, crie ou abra um workflow e adicione o nó Webhook.
2. Defina HTTP Method como POST e o path desejado (ex: waha-mensagem).
3. Copie a Test URL (ou Production URL) do nó Webhook e cole no campo acima.
4. Clique em "Salvar Webhook no WAHA" e em seguida em "Testar Disparo para n8n".
Estrutura JSON enviada ao n8n: 
{
  "event": "message",
  "session": "DaviWhats",
  "payload": {
    "from": "5511999999999@c.us",
    "fromMe": false,
    "body": "Olá! Gostaria de agendar um horário.",
    "timestamp": 1710000000,
    "_data": {
      "notifyName": "Cliente Exemplo"
    }
  }
}
DISPARO DE MENSAGENS n8n → WhatsApp
Enviar Mensagens pelo n8n (Nó WAHA ou HTTP Request)
Você pode disparar mensagens pelo n8n de duas formas: diretamente pelo Nó WAHA (usando as credenciais no topo desta seção) ou utilizando o nó padrão HTTP Request via endpoint do BeautyFlow.
Endpoint Recomendado (BeautyFlow CRM) Zero Configuração
POST http://localhost:3001/api/whatsapp/send-notification
Formata telefone brasileiro automaticamente • Salva no histórico de notificações do CRM • Sem expor chaves no fluxo.
Body JSON (Send Body no n8n) 
{
  "phone": "{{ $json.telefone }}",
  "message": "Olá {{ $json.nome }}, seu agendamento no BeautyFlow está confirmado para {{ $json.data }} às {{ $json.horario }}!",
  "client_name": "{{ $json.nome }}"
}
Como configurar o nó no n8n:
  1. Adicione o nó HTTP Request no seu fluxo n8n
  2. Defina Method como POST e cole a URL acima
  3. Em Send Body, selecione JSON
  4. Cole o JSON usando as variáveis dinâmicas do nó anterior (ex: {{ $json.telefone }})
Serviço BeautyFlow • Disparos via WhatsApp 
curl -X POST http://localhost:3001/api/whatsapp/send-notification -H "Content-Type: application/json" -d '{"phone": "5511999999999", "message": "Olá! Teste de disparo via n8n"}'
